# Spectrum-PNX
Spectrum-PNX is an implementation of the [Spectrum](https://github.com/cooldogedev/Spectrum) proxy for PowerNukkitX servers.

---
> [!IMPORTANT]
> This plugin is on a beta version, bugs may occur. If you find an issue please report it from issues page.

---

## Getting Started

### Installation
1. Download the latest release from [releases tab](https://github.com/PowerNukkitX-Bundle/Spectrum-PNX/releases).
2. Place the JAR file into the `plugins` folder of your PowerNukkitX server.
3. Start or reload your server.

---
## For Developers
You can use specific events like `SpectrumPacketSendEvent` for even listening.
